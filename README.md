# Hari Om Mishra — Engineering Portfolio

Personal engineering portfolio showcasing my work in Java, Spring Boot,
microservices, REST APIs, React, and full-stack application development.

The portfolio is designed around project case studies, system architecture,
engineering decisions, and practical implementation rather than a traditional
template-style portfolio.

## Tech Stack

- Next.js
- TypeScript
- React
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- REST APIs
- Microservices
- MySQL
- React Hooks
- Motion for React

## Featured Projects

### Order & Inventory Microservices
Independent Order and Inventory services built with Spring Boot and REST APIs,
using separate databases and service-to-service communication.

### Full-Stack E-Commerce Platform
React + Spring Boot application featuring authentication, JWT-based
authorization, cart and checkout workflows, order history, pagination,
search, and transactional stock/order processing.

### Digital Wallet & Transaction System
Spring Boot and JPA-based transaction system supporting deposits,
withdrawals, peer-to-peer transfers, transaction history, and
concurrency-safe transaction processing.

### Task Manager Web App
React-based task management application with CRUD operations,
filtering, reusable components, hooks, and REST API integration.
